# 成果登记只读出口
python3 -m lab.source_db /tmp/source.sqlite3 init 创建合成数据库；rename 在同一事务修改机构并增加第二位作者，unlink 删除第一作者关系，delete 删除成果，prune --first 3 清理更早日志。连接器使用只读 URI 与显式读事务，不能修改来源。
transactions 是提交事务边界，changes 按 txid、ordinal 排序，before_json/after_json 保存前后值，复合键见 key_json。retention.first_tx 表示仍可完整读取的最早事务；transactions 行保留以维持单调编号。快照中可一起读取四张业务表与 MAX(txid)，之后衔接更大 txid。机构与人员主键不复用，作者关系 ordinal 有业务顺序。成果 kind 使用研合的 dataset/software/process 等值，外部 source 固定由调用者配置。
这里的日志由本地来源事务产生，包含多表关联变更；它不包含连接器状态、研合 generation 或目标索引实现。来源 WAL 模式可用两个连接演练读取快照期间的并发提交。
